# Better Trail

It lets you add a Wave Trail to all gamemodes, as well as other Wave Trail settings.

* Wave Trail to all gamemodes
* Hide Wave Trail
* Custom Wave Trail color
* Solid Wave Trail
* Custom Trail Size
* No Wave Trail Pulse
* Hide Regular Trail on top of Wave Trail
* Hide Vehicle Particles
